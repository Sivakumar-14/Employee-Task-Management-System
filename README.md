# Employee Task Management System

A full-stack Java web application to manage and assign tasks to employees with custom status tracking.

## Technical Stack
* **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
* **Backend:** Java Servlet, JDBC
* **Database:** MySQL
* **Server:** Apache Tomcat

## How to Run the Project Localhost

1. **Database Setup:** 
   Run the `database.sql` script in your MySQL Workbench to create the database and table structure.

2. **Import Project:** 
   Open Eclipse IDE and import this project as a Dynamic Web Project.

3. **Deployment:** 
   Run the project on Apache Tomcat Server and open `http://localhost:8080/TaskTracker` in your browser.
